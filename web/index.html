Tab5 web flasher

Flashes firmware onto the M5Stack Tab5's ESP32-P4 over its USB-C port.

1. Choose the firmware

Looking for the published firmware...

2. Flash it

The browser then asks for the Tab5's serial port, and this page asks you to confirm before anything is written.

Choose a firmware first.

3. Check that Launcher answers

Launcher keeps a command console on the same USB-C port. This sends it version, whoami and partitions -- all three only read -- and checks the replies, so you know firmware can be sent to it this way. Give a freshly flashed Launcher a few seconds to start; this waits up to 20. It runs by itself after Launcher is flashed.

If Launcher answers but the screen stays dark, restart it: on its first boot after other firmware, Launcher can miss the Tab5's display (M5GFX: M5Tab5 display panel was not detected), and finds it on the next one.

Not checked yet.

4. Send to the Tab5's card or USB drive

With Duplicitous running on the Tab5, this puts files on its microSD card or USB drive over the same USB-C port -- the firmware from step 1 instead of flashing it, or files from this computer -- then reads each one back to check it, and can install a .bin and boot it. Duplicitous shows what is being written while it happens.

"Test the port" checks that nothing else on this computer -- a terminal, idf.py monitor -- has the Tab5's port open as well: if something does, it takes pieces of what the Tab5 sends, and a transfer fails. It runs by itself before every Send.

Port and chip tests

The output follows the Tab5 through resets, like idf.py monitor: when it drops off USB, the page waits for it to come back and keeps reading.

If reading the chip or flashing times out, the running firmware may have turned off the USB-Serial/JTAG reset. Hold BOOT, press and release RESET, let go of BOOT, and try once more.
